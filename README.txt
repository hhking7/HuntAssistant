THE HUNT ASSISTANT 0.0.2.1 - WINDOWS x64 FOLDER RELEASE

GETTING STARTED
1. Download the entire release folder to a writable location, such as Desktop.
2. Keep all DLLs and subfolders beside TheHuntAssistant.exe.
3. Double-click TheHuntAssistant.exe and complete Twitch sign-in when prompted.

REQUIREMENTS
A 64-bit Windows 10/11 PC, the Microsoft .NET 10 Runtime (x64), and WebView2.
This version uses separate application files, like release 0.0.1.6. The .NET runtime
is not bundled. Install the .NET 10 Runtime for Windows x64 if it is not present:
https://dotnet.microsoft.com/en-us/download/dotnet/10.0
Choose the .NET Runtime installer; the SDK is not required.
Windows App SDK dependencies are included as local DLLs.
If WebView2 is missing, run Prerequisites\MicrosoftEdgeWebview2Setup.exe once.
That official Microsoft installer needs internet access.

APP DATA
Hunts, settings, and generated OBS files are saved in Documents\TheHuntAssistant.
They remain separate from this executable. Existing hunts retain their saved lists;
the updated item catalogs are used when creating new hunts.
After upgrading, refresh existing OBS browser sources once to load the new HTML.
